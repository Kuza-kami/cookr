# Cookr 🍳 — Your Cozy, Ghibli-Inspired Culinary Companion

Cookr is a beautifully crafted, highly polished, and fully interactive cooking companion for Android. Blending **Neo-Brutalist modern UI design** with warm, nostalgia-inducing **Ghibli visual aesthetics**, Cookr turns routine meal planning, grocery runs, and cooking prep sessions into an delightful, engaging companion experience.

Whether you are seeking custom meals generated by Gemini, tracking daily targets, or completing culinary commissions from Ghibli-inspired neighbors inside an interactive quest inbox, Cookr provides a delightful cooking journey.

## ✨ Features Breakdown

### 1. 🌟 Discover & Interactive Meal Planner
- **Overview**: A custom, scrollable grid featuring hand-crafted recipe catalogs categorized by tags (e.g., Quick, Ghibli Class, Sweet, Cozy).
- **Daily Progress Bar**: Displays dynamic progression towards active target limits (e.g., Calorie Target tracking).
- **Interactive Planner**: Features a Neo-Brutalist Meal Slot timeline card deck (Breakfast, Lunch, Dinner, Dessert). Users can tap to add what they are eating, updating live logs instantly.

### 2. 🪄 AI Recipe Wizard (Powered by Gemini)
- **Overview**: An multi-step wizard to guide users into expressing culinary cravings.
- **Gemini Integration**: Sends structured multi-step preference inputs (leftover ingredients, spice meters, allergies) and extracts valid, fully populated recipe instructions, cooking stats, and mock cooking timers.
- **Recipe Active View**: Fully populated step-by-step interactive navigation, completed with active progress timers, ingredients checkmarks, and custom user recipe upvoting and star reviews.

### 3. 📸 AI Photo Food Scanner
- **Overview**: A highly engaging visual capture bay allowing users to simulate active camera snapshots, choose high-fidelity preset culinary photography elements (e.g., Artisan Ramen, Avocado Toast), or link system galleries.
- **Analysis View**: Features structured model pipelines estimating carbohydrates, fats, proteins, and total calories before exporting clean entries to the local digital cookbook.

### 4. 📬 Cozy RPG Quest Inbox
- **Overview**: Interwoven messenger dashboard delivering neighborhood-friendly requests: Ghibli styled NPCs (Ponyo's Mum, Chef Jiji, Sophie) requesting specific culinary commissions.
- **Interactive Dialogs**: Supports custom text messaging, pre-baked quick replies, quest milestones, reward points coins, and full voice-assistant simulation controls.

## 🛠️ Production Recommendations: Bringing Every Component to Life

To transition Cookr from a prototype into a production-ready application deployed to the Google Play Store, implement the following standard API integrations:

### 1. Production-Grade Secure AI Integrations

To protect the server-side Gemini API pipeline, hardcoding credentials inside mobile applications is **strongly discouraged** for production because APKs can be easily decompiled and extracted.

*   **Current Setup**: The app uses `GeminiClient` accessing key variables via `BuildConfig.GEMINI_API_KEY`, secure files, and environment values.
*   **Production recommendation**: Move the API endpoint request into a lightweight **backend proxy server** (using *Firebase Cloud Functions*, *Ktor*, or *Cloud Run*) protected by **Play Integrity** or **Firebase App Check**. This restricts endpoint usage strictly to certified, unmodified instances of your official mobile application.

```kotlin
// Production Proxy Base-Url Call example substituting direct client API calls:
interface ProductionCookrApiService {
    @POST("/api/generate-recipe")
    suspend fun requestAiRecipe(@Body request: CustomUserRequest): Response<RecipeResponse>
}
```

### 2. High-Fidelity OCR & Vision Enhancements
The scanner screen handles image loaders smoothly. To convert this into a fully automatic, real-world multi-modal analyzer:
1.  **Local OCR Integration**: Use **Google ML Kit (Object Detection & Image Labeling API)**. ML Kit provides free, completely offline local classifications on Android.
2.  **Advanced Multi-Modal Pipeline**: Send the captured image bitmap directly to Firebase's **Vertex AI for Firebase SDK** (specifically utilizing the `gemini-2.5-flash` or `gemini-1.5-flash` model variants). Use structured prompt contexts asking the language model to parse food items and output deterministic JSON fields:

```kotlin
val model = Firebase.vertexAI.generativeModel("gemini-1.5-flash")
val response = model.generateContent {
    image(capturedBitmap)
    text("Identify the main dish, estimate total calories, protein, carbs, and fats. Respond in strict JSON format.")
}
```

### 3. Real Android CameraX integration
Currently, the Photo Analyzer uses high-quality simulation states to avoid physical device crashes inside web emulators. To integrate a true, real-time camera view:
Use standard Android **CameraX** jetpack dependencies inside `PhotoAnalyzer.kt`:

*   **Build Setup**:
    ```kotlin
    implementation("androidx.camera:camera-camera2:1.3.1")
    implementation("androidx.camera:camera-lifecycle:1.3.1")
    implementation("androidx.camera:camera-view:1.3.1")
    ```
*   **Preview Composables integration**:
    ```kotlin
    @Composable
    fun CameraPreviewView(onImageCaptured: (Bitmap) -> Unit) {
        val lifecycleOwner = LocalLifecycleOwner.current
        AndroidView(
            factory = { context ->
                val previewView = PreviewView(context)
                val cameraProviderFuture = ProcessCameraProvider.getInstance(context)
                cameraProviderFuture.addListener({
                    val cameraProvider = cameraProviderFuture.get()
                    val preview = Preview.Builder().build().also {
                        it.setSurfaceProvider(previewView.surfaceProvider)
                    }
                    val imageCapture = ImageCapture.Builder().build()
                    val cameraSelector = CameraSelector.DEFAULT_BACK_CAMERA
                    try {
                        cameraProvider.unbindAll()
                        cameraProvider.bindToLifecycle(lifecycleOwner, cameraSelector, preview, imageCapture)
                    } catch (e: Exception) { e.printStackTrace() }
                }, ContextCompat.getMainExecutor(context))
                previewView
            },
            modifier = Modifier.fillMaxSize()
        )
    }
    ```

### 4. Direct OS Text-To-Speech (TTS) Integration
Currently, Ghibli RPG inbox readings trigger engaging simulated notifications. You can connect this to the official system voice engines immediately:

```kotlin
class CookrTextSpeechManager(private val context: Context) : TextToSpeech.OnInitListener {
    private var tts: TextToSpeech? = null
    init {
        tts = TextToSpeech(context, this)
    }
    override fun onInit(status: Int) {
        if (status == TextToSpeech.SUCCESS) {
            tts?.language = Locale.ENGLISH
        }
    }
    fun speakText(rawMessage: String) {
        tts?.speak(rawMessage, TextToSpeech.QUEUE_FLUSH, null, "CookrMessageTTS")
    }
    fun stopSpeaking() { tts?.stop() }
}
```

## 🚀 Setup & Launch Instructions

### Requirements
*   **Android Studio Jellyfish / Koala** or newer.
*   **JDK 17 + Kotlin Gradle Plugin** (aligned setup ready built-in).
*   **API level Minimum**: 26 (Android Oreo 8.0).
*   **API level Target**: 34 (Android 14) or newer.

### Configuration Steps

1.  **API Keys Credentials (Google AI Studio Secrets)**:
    Before using the AI Recipe Wizard, provide your Gemini API Key in your development setup:
    *   Add your key inside `.env` at the project root:
        ```env
        GEMINI_API_KEY=AIzaSy...YourActualKey...
        ```
    *   Verify `.env.example` has a corresponding placeholder:
        ```properties
        GEMINI_API_KEY=GEMINI_API_KEY_PLACEHOLDER
        ```
    The application leverages **Secrets Gradle Plugin** to securely inject values directly into `BuildConfig.GEMINI_API_KEY` during the Gradle build pipeline.

2.  **Compilation & Launch**:
    Run standard Gradle assembly targets in the terminal or Android Studio:
    
    *   **Compile Debug Build**:
        ```bash
        gradle assembleDebug
        ```
    *   **Run Local Tests Verification (Unit & Robolectric)**:
        ```bash
        gradle :app:testDebugUnitTest
        ```

## 🔐 App Security & Environment Safety Warning

> ⚠️ **Security Warning**: Standard Android APKs compiling secrets inside `BuildConfig` are subject to extraction. Leak risks arise if compilation APKs containing production keys are publicly shared on public servers or open-source repositories (e.g., public GitHub files). Ensure that any live API credentials are kept separate from production builds, or secured utilizing Firebase App Check proxies or separate cloud servers!
